Core pillars

Decide how work gets done

Use the model, harness, and subscription you already have and swap any of them when you need different speed, depth, or setup. Your sessions follow you across devices and run in the editor you already work in, so agents can work while you dive into the code.

Models and Harnesses

Scale what works

You don't have to run one session or one repo at a time. Orchestrate across sessions and repos to get through your backlog faster and jump into whichever one needs your input.

Run agent sessions in parallel

Build the system, not the solution

VS Code is yours to configure. Instructions, skills, custom agents, and hooks carry your team's standards into every session, while MCP servers connect agents to the systems you already use. Shape the whole development environment with extensions, languages, debuggers, and themes so it fits the way you work.
